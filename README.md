# AUTORA — Pre-Owned Vehicle Commerce

A compact multi-page HTML/CSS/JavaScript starter for discovering, comparing and evaluating pre-owned vehicles.

Pages:
- index.html — Home
- vehicles.html — Inventory + filters
- vehicle.html — Vehicle detail + color switching + shortlist + sticky purchase bar
- compare.html — Vehicle comparison
- inspection.html — Inspection methodology/report
- login.html — Login UI only
- signup.html — Signup UI only

Structure:
assets/css/style.css
assets/css/dark-mode.css
assets/css/rtl.css
assets/js/main.js
assets/js/dashboard.js
assets/images/

No real authentication or payment backend is connected. Account-free demo flows are intentional.
